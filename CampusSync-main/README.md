# CampusSync - AI Campus Grievance Platform

An AI-powered campus grievance and management platform that helps students, faculty, and administrators report, track, and resolve campus issues efficiently.

## Features

- **Smart Complaint Submission**: AI-powered classification and priority assignment
- **Real-time Tracking**: Live status updates and timeline tracking
- **Role-based Access**: Different views for students, faculty, and administrators
- **Campus Map Integration**: Visual issue location tracking
- **Analytics Dashboard**: Insights and trends for administrators
- **Secure Authentication**: Role-based user management with Supabase

## Tech Stack

- **Frontend**: React with TypeScript, Vite, Tailwind CSS
- **Backend**: Supabase (Database & Authentication)
- **UI Components**: Radix UI with custom styling
- **State Management**: React Context API
- **Routing**: React Router

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up Supabase configuration
4. Start development server: `npm run dev`
